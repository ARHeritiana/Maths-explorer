# Map: where to look for a task

Purpose: open only the files a task needs. Find the task in the router (section 2), open the files it names, read the
area index of the folder you work in (section 4), and stop there. Do not scan the repository.

Kept current by `tests/map.test.mjs`: every source file in `site/`, `build/mxbuild/`, `scripts/` and `tests/` must be
named in this file or in its folder's `CLAUDE.md`, and every path named here must exist. When you add, rename or delete
a file, update the map in the same commit.

## 1. Never read these (generated or archived)

| Path | Why | Instead |
|---|---|---|
| `dist/**` | copies of `site/` plus build products; `make site` rewrites it | edit `site/`, `content/` |
| `site/index.html` import map, `site/slides/player.html` import map | regenerated by `make site` | never edit by hand |
| `site/js/catalogue-data.js`, `dist/js/resources-data.js`, `dist/js/enrichment-data.js`, `dist/resources/catalog.json`, `content/data/RESOURCE_PROVENANCE.json`, `content/data/build-state.json` | generated from the manifest and the inputs | `content/data/manifest.json`, then `make site` |
| `content/tex/**/*.en.tex` | generated English twins | the `.fr.tex` unit and its `.en.json` table |
| `site/js/gallery-sofa-gerver.js`, `site/js/gallery-squares-data.js` | generated curiosity data (large) | `scripts/build-gallery-data.py` |
| `docs/history/**`, `docs/LOG.md` | dated records | only when asked about the past |
| `site/vendor/**`, `site/fonts/**`, `site/js/icons.js` body | third-party | `site/vendor/README.md` |

`.ignore` hides `dist/` and `docs/history/` from ripgrep, Grep and Glob. Use `git grep` or a path argument if you
really need them.

## 4. Area indexes (read only the one you work in)

| Folder | Index | Holds |
|---|---|---|
| `site/` | `site/CLAUDE.md` | hand-written web source: every JS module by feature, styles, slide player |
| `site/js/lab/` | `site/js/lab/CLAUDE.md` | the laboratory: engine, shell, templates, models, one file per experiment |
| `content/` | `content/CLAUDE.md` | TeX courses, slide decks, manifest and other data |
| `build/mxbuild/` | `build/mxbuild/CLAUDE.md` | the pipeline (`make tex`, `site`, `catalog`, `check`) |
| `scripts/` | `scripts/CLAUDE.md` | course, slide and university builders |
| `tests/` | `tests/CLAUDE.md` | which test covers which module |
| `docs/` | `docs/CLAUDE.md` | which document is current |

Root files: `CLAUDE.md` (entry), `AGENTS.md` (other agents), `HANDOFF.md` (state and task queue),
`PROJECT_BRIEF.md` (governing rules), `README.md` (humans), `Makefile`, `package.json`, `.github/workflows/`
(`checks.yml` CI, `pages.yml` GitHub Pages deploy of `dist/` on push), `.openai/` (ChatGPT Sites hosting config).

## 5. Single sources of truth (change here, nowhere else)

| Fact | Lives in | Fans out to |
|---|---|---|
| colours and fonts of the site | CSS custom properties in `site/styles/explorer.css` | every page; JS canvases read them through `object-kit.js` `palette()`; challenge cards use `--c1..--c8` via `site/js/challenges/common/kit.js` `colour()` |
| colours of the PDFs | `content/tex/core/mx-layout.sty` | every PDF on rebuild |
| courses, chapters, titles, languages | `content/data/manifest.json` | `catalogue-data.js`, catalogue, slides index, chapter pages |
| everything about one challenge | `site/js/challenges/<id>/` | card, statement, checker, original, emblem, hints, activity, solution |
| maths notation FR/EN | `content/tex/core/mx-notation.sty` + `build/mxbuild/notation.py` | PDFs and web |
| camera and drag behaviour | `site/js/canvas-navigation.js` (2D), `site/js/camera3d.js` (3D) | site canvases, laboratory (`site/js/lab/engine.js`) and slide player |
| asset URLs and versions | `site/js/data-loader.js` `assetHref` | every link and download |
| lab references `"<experiment>"` / `"<experiment>/<mission>"` | the experiment files; the one resolver `resolveRef` in `site/js/lab/registry.js` | lab page route, `manifest.json` `catalog.chapters[].labs`, slide `WIDGETS` (`lab('...')`), chapter pages, `tests/lab-links.test.mjs` |
| how a number is written (≈ rounded, = exact; decimal comma) | `site/js/lab/format.js` `makeFormat` | every readout, formula and canvas label of the laboratory |

Rule: when a change touches several files, the fact belongs in one place. Challenges follow it since 18 October 2026
(one folder each); propose the same move when you meet another fact written in several files.
