# content/: index

Sources of everything the build publishes. Generated files sit beside some sources: never edit them.

| Path | Holds | Edit? |
|---|---|---|
| `data/manifest.json` | catalogue source of truth: keys `catalog` (courses, chapters), `books` (course mains), `companion`, `university`, `texConverted` | yes, then `make site` |
| `data/enrichment.json` | enrichment workshops, both languages, maths as `$...$` | yes, then `make site` |
| `data/glossary.json` | FR/EN terminology | yes |
| `data/RESOURCE_PROVENANCE.json`, `data/build-state.json` | generated by `make catalog` / `make site` | never |
| `tex/core/` | `mxbook.cls` and `mx-*.sty`: frame, palette, environments, notation (`docs/TEX_STYLE_GUIDE.md`) | yes; rebuilds every PDF |
| `tex/courses/<course>/**/<unit>.fr.tex` | French unit: the source of a course PDF | yes |
| `tex/courses/<course>/**/<unit>.en.json` | reviewed translation table of that unit (prose only) | yes |
| `tex/courses/<course>/**/<unit>.en.tex` | English twin, GENERATED by `build/mxbuild/twin.py` | never |
| `tex/courses/enrichment/*` | GENERATED from `data/enrichment.json` (except `quadratic-presentation`) | never |
| `tex/lectures/` | Beamer lecture editions (`scripts/build-lecture-slides.py`) | yes |
| `tex/university/foundations/` | university foundations sources (`scripts/build-university.py`) | yes |
| `university/module-maths/` | applied mathematics module (`scripts/build-module-maths.py`) | yes |
| `slides/<deck>.json` | authored decks (English Terminale, Seconde, Première) | yes, then `make slides` |
| `slides/draft/terminale-<NN>.fr.json` | French Terminale drafts with figure code | yes |
| `slides/university/` | university slide decks | yes |

Courses: `seconde`, `premiere`, `terminale`, `expertes`, `stmg`, `automatismes`, `enrichment`. Typical unit folders:
`chapitres/C<NN>.fr.tex`, `evaluations`, `corriges`, `figures`. Builder per course: `build/mxbuild/pipeline.py`
`COURSES` (it names the script in `scripts/`).

Workflow for a PDF change: edit the `.fr.tex` (and its `.en.json` segment if prose changed), run
`make tex COURSE=<course>` (TeX Live needed, packages in `docs/ARCHITECTURE.md`), then `make site`.
Rules: translate prose only (`docs/ADR-0001-tex-i18n.md`); environments and macros in `docs/TEX_STYLE_GUIDE.md`;
no names of owner, school or city; every computed result verified by code (scripts kept in the owner's private area, outside this repository).

`university/fourier/lessons.py`: original French Fourier lesson and exercise source shared by the web and PDF editions.

Fourier sequence titles, summaries and prerequisites are derived from the original lesson source by content_index.py. `data/fourier-build.json` is a generated, tracked output receipt.
