# site/js/gallery/: index

The gallery exhibits ("Lire" > "Curiosités"), one module per exhibit with its pure model, plus the shared kit. Paths below are
relative to `site/js/gallery/`. Imports between these files use `./`; shared modules one level up use `../`
(`../object-kit.js`, `../math.js`). The page code is in `site/js/welcome.js` and `site/js/app.js` (see `site/CLAUDE.md`).

| File | Holds |
|---|---|
| `gallery-objects.js` | Fourier circles (Madagascar opens on 24 circles), Mandelbrot/Julia explorer |
| `gallery-math.js` | pure maths of the gallery (escape times, DFT, Madagascar outline) |
| `gallery-additions.js` | six experiment-first gallery entries (with the four colour map) and source labels |
| `gallery-models.js`, `gallery-kit.js` | Voronoi clipping, descent timing, film area minimisation; shared exhibit lifecycle |
| `gallery-voronoi.js`, `gallery-fastest.js`, `gallery-soap.js` | draggable territories, bead races, rotatable film |
| `gallery-knot-model.js` | legacy pure braid/invariant helpers and verified mirror certificate, retained for model tests |
| `gallery-knot-render.js` | shared solid-colour strand drawing with depth-ordered crossing gaps for the card and full explorer |
| `gallery-soap-model.js` | 13 fixed-topology spatial meshes and a separate tetrahedral junction solver; movable frame handles (`frameHandleIds`, `moveFrameHandle`) |
| `gallery-context.js` | mathematical ideas, historical context and applications for all gallery entries |
| `gallery-hat-model.js`, `gallery-hat.js` | H7/H8 geometry and continuous hat-family explorer |
| `gallery-four-colour-model.js`, `gallery-four-colour.js` | four colour exhibit: nine menu choices, point-contact and disconnected-country examples, connected-country border editor with undo, shared-border neighbours and exact backtracking colouring |
| `gallery-curiosities.js` | catalogue lines (and `links`) of the Game of Life, square packing, moving sofa, inscribed square, opaque square and equidecomposition curiosities |
| `gallery-equidecomposition-model.js`, `gallery-equidecomposition.js` | equidecomposable polygons (Wallace-Bolyai-Gerwien): pure ear clipping, validator, dissection stages in eight steps; presets, pairs, polygons drawn or typed as x,y pairs; catalogue line in `gallery-curiosities.js` |
| `gallery-sofa-model.js`, `gallery-sofa.js` | moving sofa: L-shaped hallway, pose test, penetration and `pushOut` (the walls push the sofa), `resolve` (moves, turns about the centroid, optional guide), Hammersley's family and motion, Gerver's motion, freehand sofas |
| `gallery-sofa-gerver.js` | GENERATED by `scripts/build-gallery-data.py sofa`: Gerver's sofa (outline, rotation path, constants) from Romik's equations |
| `gallery-inscribed-model.js`, `gallery-inscribed.js` | inscribed square: closed spline through control points, self-crossing test, random curves, numerical search for inscribed squares and rectangles; draw, reshape, add or delete points |
| `gallery-opaque-model.js`, `gallery-opaque.js` | opaque square: gaps of a barrier in each direction, opacity check, preset barriers; draw segments, turn the light |
| `gallery-life-model.js`, `gallery-life.js` | Game of Life: B3/S23 on the unbounded plane, presets (oscillators, ships, Gosper gun, long evolutions); drawing, play, step |
| `gallery-squares-model.js`, `gallery-squares.js` | unit squares in a square: separating-axis overlap test, frame, records (status proved, claimed, open), best known packings n = 1 to 28, exact constructions of 5 and 10; drag and turn |
| `gallery-squares-data.js` | GENERATED by `scripts/build-gallery-data.py squares`: best known packings and bounds for n = 1 to 28 (the squares project, CC BY 4.0) |
| `gallery-knots.js`, `gallery-knot-geometry.js`, `../knot-catalogue.js` | 44 verified spatial curves, preview-style strands, true projections, F3 colours and continuous examples |
| `gallery-room.js` | the unilluminable room (`#gallery/mirrored-rooms`, entry in `../illumination-content.js`): stage first (chips, tools, hint, zoom, readout, legend) and panel tabs Explorer, Dessiner, Comprendre, Défis (room thumbnails, ray count up to the device ceiling, reflections, light step by step, editor buttons, short explanation, four challenges); canvas in `../illumination-view.js` |
| `gallery-inference.js` | mounts the six inference laboratories from gallery cards (content in `site/js/inference-content.js`) |
| `gallery-gomboc.js` | the Gömböc page: free orbit, tip and push, map of the body (maths in `site/js/gomboc-*.js`) |
| `gallery-fair-division.js` | mounts the cake and goods laboratories (content in `site/js/fair-division-content.js`) |
| `gallery-topology.js` | reuses the guided topology laboratories (content in `site/js/topology-content.js`) |
| `gallery-dynamics.js` | mounts the pendulum, three-body and logistic simulations in gallery entries (content in `site/js/dynamics-content.js`) |
